## 🛠 Featured Projects

| Project | What it does | Stack |
|---|---|---|
| 🎸 **[NeuroPedal](https://github.com/Quinnsmitth/NeuroPedal)** | Predicts guitar-pedal **drive** and **tone** settings from raw audio.
